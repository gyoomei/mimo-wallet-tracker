# 🦊 MiMo Wallet Tracker

**AI-Powered EVM Wallet Intelligence Dashboard** — 100% Free, No API Key Required

🔗 **Live:** https://gyoomei.github.io/mimo-wallet-tracker/

## Features

- **Real-time Balance** — Fetches live ETH/token balances via Blockscout API
- **Multi-Chain** — Ethereum, BSC, Polygon, Base, Arbitrum
- **Transaction History** — View recent txs with method decoding (swap, approve, mint, etc.)
- **Token Holdings** — See all ERC-20 tokens held by any wallet
- **AI Risk Analysis** — Client-side pattern detection: failed txs, large transfers, approvals
- **Smart Alerts** — Auto-detects suspicious activity
- **Portfolio Value** — USD value tracking with live ETH price
- **Persistent Storage** — Wallets saved in localStorage
- **No Backend** — Pure static site, works on GitHub Pages

## Tech Stack

- Pure HTML/CSS/JS (no build step)
- Blockscout V2 API (free, no API key)
- localStorage for persistence
- GitHub Pages hosting

## API

Uses [Blockscout API v2](https://docs.blockscout.com/) — completely free, no registration needed.
